# @dynamis/web

Placeholder workspace package created by **RES-96** so the root pnpm workspace is
valid and lockable under Node.js 24 LTS.

No product surface is implemented here. The React + Vite + TypeScript +
TanStack Query + Zustand + Apache ECharts + PixiJS + Three.js visual laboratory
is **RES-101** and is explicitly out of scope for RES-96.

Run the workspace-level checks from the repository root:

```bash
pnpm install --frozen-lockfile
pnpm run web:typecheck
pnpm run web:lint
```
