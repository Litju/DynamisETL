# ADR-001: add a sports semantic overlay

Status: accepted for V4.

Keep Dataset/Session/Trial/Stream/Artifact/Run/Metric and provenance/quality/rights as the scientific core. Add sport, competition, edition, team, contest, participation, periods, roster membership and an explicit Session-to-Contest bridge above it.

This supports multi-sport match semantics without renaming laboratory trials or duplicating athlete identity. Unknown facts remain nullable or absent. Provider IDs are aliases and equal display names never merge entities.
